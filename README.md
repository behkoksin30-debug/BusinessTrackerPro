# Biz Tracker Pro

顾客 / OPP 名单 / 生日 / 跟进对象 / ABO 追踪系统的 **Pro 版本**,带完整的账号登录与下线账号管理功能。

> ⚠️ **这是一个独立的项目,跟你原本的系统完全分开。**
> 请把它部署成一个**全新的 Railway 项目**(不要覆盖你原本正在用的那个),这样万一 Pro 版本这边出状况,完全不会影响你原本的系统继续使用。

## 这个 Pro 版本新增了什么

- **账号登录系统**:第一次打开网站时,需要设置一个管理员账号(用户名 + 密码),之后每次使用都要登录
- **下线账号管理**:登录后可以在「设置」面板里,帮每一位下线开一个属于他自己的账号
- **各自资料独立**:每个账号(包括你自己和每个下线)的顾客/OPP/生日/ABO/跟进对象资料都是完全独立的,互相看不到
- **上线可以查看下线资料(只读)**:你可以在首页切换查看任何一个下线的完整资料,但不能帮他们编辑,避免不小心改到别人的东西

## 本地运行

```bash
npm install
npm start
```

打开浏览器访问 `http://localhost:3000`,第一次会要求你设置管理员账号。

## 部署到 GitHub + Railway(独立的新项目)

### 第一步:上传到 GitHub(建议开一个新仓库,不要用原本那个)

```bash
git init
git add .
git commit -m "初始提交:Biz Tracker Pro"
```

然后在 GitHub 上新建一个**全新的空仓库**(不要勾选自动生成 README),再执行:

```bash
git remote add origin https://github.com/你的用户名/新仓库名.git
git branch -M main
git push -u origin main
```

### 第二步:部署到 Railway(建议开一个新项目)

1. 打开 [railway.app](https://railway.app),用 GitHub 账号登录
2. 点击 **New Project → Deploy from GitHub repo**
3. 选择刚才推送的**新仓库**(不要选到你原本那个项目)
4. Railway 会自动识别 `package.json`,执行 `npm install` 和 `npm start`
5. 部署完成后,在项目的 **Settings → Networking** 里点击 **Generate Domain**,即可获得一个公开访问的网址

几分钟内网站就能上线,之后每次 `git push` 到这个新仓库,Railway 会自动重新部署**这个 Pro 版本**,完全不会影响你原本的系统。

## ⚠️ 让数据不会因为重新部署而丢失(必做)

Railway 每次重新部署都会重置文件系统,所以要给这个新项目挂一个**持久化卷(Volume)**,数据才会一直保留:

1. 打开这个 Pro 版本的 Railway 项目,进入服务的 **Settings → Volumes**
2. 点击 **New Volume**
3. **Mount path** 填 `/data`
4. 再打开 **Variables**,新增一个环境变量:`DATA_DIR` = `/data`
5. 保存后 Railway 会自动重新部署一次

设置好之后,所有账号的资料都会一直存在 `/data` 底下,不会再因为改代码重新部署而消失。这一步只需要做一次。

本地开发不用设置 `DATA_DIR`,数据会照常存在项目目录下。

## 第一次使用怎么开始

1. 部署完成、打开网址后,会看到「创建你的账号」画面 —— 这个就是你的**管理员账号**,请填一个你自己的用户名和密码(密码至少 4 位)
2. 登录进去后,点右上角齿轮图标打开「设置」,往下滑会看到「管理下线账号」区块
3. 在那里逐一帮每位下线填用户名 + 密码,点「新增」,就能开出一个账号给他们
4. 把对应的用户名密码告诉每位下线,他们就可以用自己的账号登录、上传自己的资料
5. 你自己登录后,首页副标题下面会有一个「查看资料」选单,可以切换查看任何一个下线的完整资料(只能看,不能改)

## 📱 把网站变成手机上的"App"图标

现在网站已经支持"添加到主屏幕",效果就像一个真正的 App:有自己的图标、打开后没有浏览器网址栏,全屏显示。

**iPhone(Safari 浏览器):**
1. 用 Safari 打开你的网站
2. 点底部的分享图标(方框加箭头↑)
3. 往下滑,点 **添加到主屏幕**
4. 点右上角 **添加**

**安卓(Chrome 浏览器):**
1. 用 Chrome 打开你的网站
2. 点右上角的 **⋮** 菜单
3. 点 **添加到主屏幕** 或 **安装应用**
4. 确认添加

添加后主屏幕上会出现一个图标,点开就跟打开一个 App 一样。每个人(你和每位下线)都可以各自在自己手机上添加,打开后各自登录自己的账号。

## 项目结构

```
biz-tracker-pro/
├── server.js                 # 后端服务,提供账号系统与所有资料的 API
├── public/
│   ├── index.html            # 前端页面(含登录/设置账号画面)
│   ├── manifest.json         # PWA 配置(让网站可以添加到主屏幕)
│   ├── icon-192.png          # App 图标
│   ├── icon-512.png          # App 图标(大尺寸)
│   └── apple-touch-icon.png  # iPhone 专用图标
├── package.json
└── data/                     # 运行后自动生成,存放所有账号的资料
    ├── users.json            # 所有账号(用户名、加密后的密码等)
    └── users/
        └── <用户名>/
            ├── data.json         # 顾客资料
            ├── prospects.json    # OPP 名单
            ├── birthdays.json    # 生日名单
            ├── abos.json         # 跟进对象
            ├── partners.json     # ABO(正式合伙人)
            └── dashboard.json    # 首页展示区(海报/标语/公告)
```

## 账号与安全提醒

- 密码是加密存储的(不会以明文保存),但请还是提醒下线不要用他们其他重要账号的密码
- 目前登录状态存在服务器内存里,如果 Railway 重启服务器,所有人都需要重新登录一次,这是正常现象
- 只有你(管理员账号)能新增/删除下线账号,下线自己无法新增其他账号,也看不到彼此的资料
